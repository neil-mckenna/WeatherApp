## Project Overview
This project is part of the Software Engineering coursework. We are building a cross-platform app in **C# MAUI** to monitor **air quality**, **water quality**, and **weather conditions** using real-time and historical sensor data.

## Features
✔️ Real-time environmental data monitoring  
✔️ Multi-role access (Scientist/Manager/Admin)  
✔️ Historical data analysis  
✔️ Automated reporting


The app supports three user roles:
- **Environmental Scientist**: Analyze data, view maps, generate reports.
- **Operations Manager**: Monitor sensor status, schedule maintenance.
- **Administrator**: Manage users, ensure system security, update sensor configs.

Focus is on **high-quality, maintainable code**, using **GitHub for version control**, **unit testing**, **UML documentation**, and **ethical AI use**.
